# ArtBot — ANSI 블록 아트 챌린지

## 배경

지하실 서버에서 오래된 BBS용 ANSI 아트 도구 `artbot`이 발견되었습니다.
이 프로그램은 문자열을 입력받아 터미널에 색이 입혀진 블록 문자
아트(ANSI escape code + `█` 문자)를 그려줍니다. 그런데 정확히 *어떤
글꼴*로, *어떤 색 규칙*으로 그리는지는 프로그램만 알고 있습니다.

당신의 목표는 이 프로그램이 그릴 **타겟 문자열**의 정확한 출력을
바이트 단위로 재현해서 제출하는 것입니다.

## 받은 파일

- `artbot` (또는 `artbot.exe`) — 실행 파일 (소스코드는 제공되지 않습니다)
- `sample/HELLO.ans`, `sample/WORLD.ans` — 프로그램이 실제로 그린 예시 출력
  (아래 "사용법"의 `render` 커맨드로 직접 재현해서 검증해볼 수도 있습니다)

## 타겟 문자열

```
CTFKOREA
```

이 문자열을 `artbot`이 그렸을 때 나오는 **정확한 바이트 출력**을
만들어서 `answer.ans` 파일로 저장하세요.

## 사용법

```
# 데모 문자열 목록 확인
./artbot --list-demo

# 데모 문자열 렌더링 (HELLO, WORLD만 허용됩니다)
./artbot render HELLO

# 당신이 만든 answer.ans 파일이 정답인지 검증
./artbot verify CTFKOREA answer.ans
```

`render` 서브커맨드는 위 목록에 있는 문자열만 그릴 수 있습니다. 목표
문자열(`CTFKOREA`)을 직접 `render`로 넣어봐도 프로그램은 그려주지
않습니다 — 그건 이 챌린지가 요구하는 방식이 아닙니다.

## 제출

`verify` 커맨드가 `PASS`를 출력하는 `answer.ans` 파일을 제출하세요.
`FAIL`이 나오면 아직 정답이 아닙니다.

## 힌트

- 예시로 주어진 두 출력(`HELLO`, `WORLD`)의 글자 모양을 잘 보면, 어떤
  스타일의 아트인지 눈으로도 어느 정도 알아볼 수 있을 겁니다. 하지만
  "그럴듯해 보이는" 걸로는 부족합니다 — 정답은 딱 하나의 정확한 글꼴로만
  만들어지고, `verify`는 바이트 단위 완전일치로만 판정합니다.
- 색 규칙도 예시 출력 안에 이미 다 드러나 있습니다. 잘 뜯어보세요.
- 한 줄씩 눈으로 비교하며 알아내는 것보다, 검증 가능한 방법으로
  후보들을 자동으로 걸러내는 편이 훨씬 빠릅니다.
